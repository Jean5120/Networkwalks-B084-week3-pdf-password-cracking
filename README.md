# PDF Password Cracking | Week 3 Cybersecurity Lab

## Project Overview

As part of my Week 3 cybersecurity training with NetworkWalks, I completed a practical exercise focused on PDF password security and password recovery.

The exercise involved extracting password hashes from protected PDF documents and using John the Ripper to perform password-cracking operations.

## Tools Used

- **John the Ripper:** Password auditing and hash-cracking tool.
- **NetworkWalks:** Cybersecurity training environment and practical lab exercises.

## Practical Tasks

1. Identified password-protected PDF documents.
2. Extracted password hashes from the PDF files.
3. Prepared the extracted hashes for password auditing.
4. Used John the Ripper to perform password-cracking operations.
5. Successfully recovered the PDF passwords.
6. Verified the recovered passwords against the protected documents.

## Skills Demonstrated

- Password security assessment
- Hash extraction
- Password auditing
- Command-line operations
- Practical use of cybersecurity tools
- Understanding password vulnerabilities

## Key Takeaway

This exercise provided practical exposure to how password hashes can be extracted and tested, highlighting the importance of strong passwords and secure authentication practices.

**Note:** All activities were conducted within an authorised cybersecurity training environment.
